Haight Banking

Online Banking System

Project description

• Background

Client: Montclair State University - IT Department

Date: Mar 2022 – Apr 2022

Type: Web Application

As part of a team of 4 members, I worked on a showcase project assigned by an institution of technology. Our project, Haight Banking, is an online banking web application that allows users to access their own accounts and history pages. We also developed an admin page with automated reporting processes and an audit log, making it easy to view user activities such as deposits, withdrawals, and transfers. Additionally, our application features a demo deposit function for testing purposes.

• Problem

The traditional banking system can be time-consuming and inconvenient, requiring customers to physically visit a branch or ATM to conduct transactions.

Solution:

Haight Banking addresses the need for a secure and accessible online banking platform for users to manage their finances remotely. With features such as user account and history pages, as well as an admin page with automated reporting processes, the application streamlines banking activities and provides transparency for both users and administrators. Additionally, the demo deposit function allows users to test the platform without risking actual funds.
